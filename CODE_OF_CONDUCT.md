# Code of Conduct

## Our pledge

We are committed to making participation in this project a welcoming and respectful experience for everyone, regardless of background, identity, experience level, or point of view.

## Expected behavior

- Be kind, patient, and constructive.
- Discuss profiles and contributions respectfully.
- Accept feedback gracefully and focus on the work.
- Respect a profile owner's request to correct or remove a listing.
- Keep criticism specific and free of personal attacks.

## Unacceptable behavior

Harassment, discrimination, intimidation, personal attacks, doxxing, and publishing private information without consent are not acceptable.

## Enforcement

Project maintainers may edit or remove content and may close or reject contributions that violate this Code of Conduct. For a conduct concern, contact the project maintainer through [their GitHub profile](https://github.com/Shivansh1251). Do not post private information in a public issue.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
