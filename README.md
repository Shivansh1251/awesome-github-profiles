## What makes a profile worth featuring?

This list aims to help people find useful examples, not to rank developers. We consider profiles that:

- Make it easy to understand who the developer is and what they build.
- Show original projects, open-source contributions, or other useful public work.
- Use a profile README or profile layout that teaches readers something they can adapt.
- Include accurate, respectful descriptions and links to the original GitHub profile.

There is no minimum follower count, star count, employer, or experience level. Students, new contributors, maintainers, and experienced developers are welcome.

## Submit a GitHub profile

Open a pull request that adds one entry to [profiles.json](profiles.json). Profile owners are encouraged to submit their own profile. You can also [suggest a profile with an issue](https://github.com/Shivansh1251/Awesome-github-profiles/issues/new?template=suggest-a-profile.yml).

1. Fork this repository and create a branch.
2. Add the GitHub username, display name, focus, and a short factual description to profiles.json.
3. Run the README generator shown in [CONTRIBUTING.md](CONTRIBUTING.md).
4. Open a pull request and explain what readers can learn from the profile.

The README preview is generated from the profile list, so you do not need to copy or upload anyone's avatar. Please read the [contribution guide](CONTRIBUTING.md) before submitting.

## Build a stronger profile README

A useful GitHub profile gives visitors a clear next step. Consider adding:

- A concise introduction that says what you work on.
- A few selected projects, each with a plain-language description and a working demo or repository link.
- Skills and interests that match the work you want people to notice.
- Links to a portfolio, writing, or contact channel you are comfortable sharing.
- A clean layout that works without animated widgets or third-party stats services.

GitHub explains how to [create a profile README](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme) and how to [use your GitHub profile to enhance your resume](https://docs.github.com/en/account-and-profile/tutorials/using-your-github-profile-to-enhance-your-resume).

## Frequently asked questions

### What are the best GitHub profiles to use for inspiration?

“Best” depends on what you want your profile to communicate. This directory highlights public profiles for their clear presentation, useful projects, or profile README ideas. Browse the notes in the directory and choose examples that fit your goals.

### How do I add my profile to this GitHub profiles list?

Submit a pull request with your username and a short, factual description in [profiles.json](profiles.json). The [contribution guide](CONTRIBUTING.md) has the exact steps. You can also use the profile suggestion issue form.

### Do I need lots of followers or repositories?

No. We do not use follower counts, stars, or repository totals as entry requirements. A clear profile and a useful example are what matter.

### Can I nominate someone else's GitHub profile?

Yes. Link to their public profile and explain what is useful about it. Keep the description factual and respectful. Profile owners can request edits or removal.

### Is this a ranked list?

No. It is a curated directory, not a contest or an endorsement of every view held by a listed person.
